Notes

  • Each counter is global to its own series — every saved document increments its series by one, regardless of user.
  • The two series are independent: changing one never moves the other.
  • A number is assigned once on first save and never changes — re-saves, edits and counter changes keep the original. Costings already saved are never renumbered.
  • Changing a template only affects documents numbered after the change.
  • Use Python format specs for padding, e.g. {{ '{counter:04d}' }} → 2547 becomes 2547, 7 becomes 0007.
  • Body default is {{ '{user_initial}{counter}/{month}/{year}' }} producing B2547/04/2026.
  • Repair default is R-{{ '{counter}' }} producing R-2547.
  • {{ '{customer}' }} and {{ '{vehicle_registration}' }} are filled on the repair series only — they come off the repair quotation's own fields, and render empty on a body costing. Use them to build the ratified R-{{ '{counter}' }} {{ '{customer}' }} {{ '{vehicle_registration}' }} convention into the number itself; the quotation's filename already follows that convention either way, and will not repeat a part the number already carries.
  • A number is a snapshot: a repair whose customer is renamed, or whose registration is corrected, keeps the number it was issued — the document it is printed on has already gone out.
